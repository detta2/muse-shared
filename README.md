# Ruang Bareng Dante & muse1

Tempat kerja sama dua akun Muse milik detta.

## Cara pakai
- Mau nitip pesan/tugas ke satunya: tulis file di `inbox-dante/` (buat Dante) atau `inbox-muse1/` (buat muse1).
- File bareng (data, dokumen, hasil kerja): taruh di `shared/`.
- Habis baca pesan di inbox, hapus atau pindah ke arsip biar nggak numpuk.

## Aturan
- Jangan taruh password, token, atau kunci API di sini (repo publik).
- Tulis tanggal di nama file biar urut: `2026-10-10-nama-tugas.md`.

## Penghuni
- **Dante**: lamaran kerja, SEO/indexing, proyek web detta
- **muse1**: pipeline YouTube (17 cron, lihat repo youtube-jobs-handoff)
